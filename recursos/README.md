# 📚 Recursos de la tarea

En este directorio encontrarás distintos recursos de apoyo para ayudarte a definir, diseñar y desarrollar tu aplicación.

## 🌐 Ejemplo de aplicación real

Consulta un ejemplo de una [aplicación web real](./1-ejemplo-aplicacion-real.md) en el que te muestro sus diferentes interfaces y funcionalidades.

Utilízalo como referencia para entender mejor el tipo de aplicación que puedes desarrollar y para obtener ideas sobre la organización de la información y la interacción con los datos.

## 🖥️ Interfaces de ejemplo

En el directorio [`interfaces`](./interfaces) encontrarás varias interfaces de ejemplo en formato `.html` desarrolladas para **BolsaSmart**.

Puedes abrir los archivos directamente en el navegador para ver cómo podrían plantearse algunas de las interfaces y funcionalidades solicitadas en la tarea.

> [!NOTE]
> 
> Estos ejemplos son únicamente orientativos. No es necesario reproducir su diseño ni su estructura; puedes adaptarlos libremente a la temática y necesidades de tu proyecto.

## 🔌 APIs disponibles

Consulta la [lista de APIs](./2-lista-apis.md) que he recopilado para ayudarte a elegir la temática del proyecto y realizar pruebas con diferentes fuentes de datos.

Antes de comenzar el desarrollo, comprueba que la API seleccionada:

- proporciona los datos necesarios para cumplir los requisitos de la tarea;
- puede utilizarse desde tu aplicación web;
- dispone de los permisos o credenciales necesarios, si los requiere.

> [!TIP]
> 
> Utiliza **Postman** para probar los endpoints de la API, revisar los datos que devuelve y comprobar los parámetros o métodos HTTP necesarios antes de integrarla en tu aplicación.
