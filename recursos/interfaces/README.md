# 🖥️ Interfaces de ejemplo

En este directorio encontrarás ejemplos de las distintas interfaces gráficas y funcionalidades propuestas en el enunciado de la tarea.

Todos los ejemplos están basados en la aplicación de referencia **BolsaSmart** y están pensados para ayudarte a visualizar posibles soluciones antes de desarrollar tu propio proyecto.

> [!NOTE]
> 
> Los ejemplos son únicamente orientativos. No es necesario reproducir su diseño, estructura ni temática. Puedes adaptarlos libremente a las necesidades de tu aplicación.

## 1. 📊 Interfaz de Resumen

- [Resumen](./1_resumen.html)

Esta interfaz muestra un posible punto de entrada a la aplicación mediante un ranking de elementos acompañado de información relevante.

## 2. 📈 Interfaz de Visualización de Datos

Puedes consultar dos ejemplos diferentes:

- [Gráfico interactivo](./2_visualizacion_datos_grafico.html)
- [Tabla comparativa](./2_visualizacion_datos_tabla_comparativa.html)

Ambos ejemplos muestran distintas formas de ampliar y representar la información de los datos seleccionados por el usuario.

## 3. ⭐ Funcionalidad Extra

Puedes consultar dos posibles funcionalidades adicionales:

- [Favoritos](./3_funcionalidad_extra_favoritos.html)
- [Filtros o búsqueda](./3_funcionalidad_extra_filtros_busqueda.html)

Estas interfaces muestran ejemplos de interacción adicional con los datos de la aplicación, como guardar elementos de interés o filtrar la información mostrada.
